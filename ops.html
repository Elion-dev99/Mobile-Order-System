① Slack Incoming Webhook を作成

  1. Slack App を新規作成（From scratch または From a manifest）
  2. マニフェスト利用時は下の「マニフェストをコピー」→ Create from Manifest に貼付け
  3. 左メニュー Incoming Webhooks → Activate を On（またはアプリをワークスペースにインストール）
  4. Add New Webhook to Workspace → 通知したいチャンネルを選択
  5. 表示された https://hooks.slack.com/services/... をコピーして②へ
