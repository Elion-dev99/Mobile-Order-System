      Cardinal — 双AI相互監視

      通信障害 → 自動メンテ テスト
      
        
      本番を壊さず、Cardinal がメンテを入れる経路を確認します。Cursor エージェントは起動しません（クレジット消費なし）。Ops鍵が必要です。
      
        
        
          
      1. エッジドリル — /api/maintenance に模擬障害メンテを書き込み、客席ブロックを確認
        2. 
          
      2. tickドリル — Cardinal tick に simulateUnhealthy を付けてサーバー経路を確認
        3. 
          
      3. 確認後は「ドリル解除」で自動メンテだけ戻す（手動メンテは触らない）
        4.

      Firebase Auth（特権書き込み）
      
      
      店舗作成・メニュー・注文削除・リード閲覧は Firebase ログイン必須です。Store フロア端末と厨房ステータス更新は Auth 不要です。
      
      
      
      
      
        
        
      
      

      
      Ops API シークレット
      
      
      Cloudflare の OPS_API_SECRET と同じ値。Cardinal / Incident / クライアントWebhook通知に必要です。既定ではこのタブのセッションにのみ保持します。
