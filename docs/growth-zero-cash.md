# ゼロ現金マーケティング（Cursor自走プレイブック）

| 項目 | 内容 |
|------|------|
| 制約 | **創業者は広告費を出さない**。成長費用はプロダクトが稼いだ売上（年払い・初期）からしか使わない |
| 目的 | リード → トライアル → Growth年払いを、**オーガニック導線だけ**で回し、Cursor Agents の利用枠を自己調達する |
| 実装 | `js/growth.js`（透かし・紹介・UTM・共有キット） |

---

## 1. 生存ループ（お金の流れ）

```text
客席透かし / デモ共有 / 店舗紹介投稿
        │
        ▼
   LP（ref + UTM付き）
        │
        ▼
  リード（Firestore）+ Discord
        │
        ▼
  14日トライアル → Growth 年払い（初回 ≈ ¥20万弱）
        │
        ▼
  その売上の一部で Cursor / Cloudflare を賄う
```

**損益の感覚:** Growth年払い1件 ≈ Cursor Ultra + Agents を数ヶ月まかなえる。  
広告を買わず、**紹介とデモ体験**で1件取れば十分生存できる。

---

## 2. プロダクトに仕込んだ無料チャネル

| チャネル | 場所 | 仕組み |
|----------|------|--------|
| 客席透かし | ゲスト画面右下 | `Powered by QuickOrder / 無料で始める` → LP（`ref=店舗ID`） |
| 注文状況CTA | status | 店舗オーナー向け「同じ仕組みを導入」＋デモ共有 |
| 店舗紹介キット | Store | 投稿文コピー / 紹介LPコピー / デモURL（広告費ゼロ） |
| 紹介クレジット | localStorage | 共有3回ごとに +7日クレジット（Opsが目視で付与） |
| 属性付きリード | LP | `ref` / `utm_*` をリードに保存 → どの店の紹介か追える |
| SEO | LP | description / OG / JSON-LD / canonical |

## 3. Cursor が毎週やる作業（現金ゼロ）

創業者の財布を使わず、エージェントが実行できることだけ列挙する。

### 毎週（30〜60分相当のエージェント作業）

1. **デモURLを1本、投稿用に磨く**  
   `https://mobile-order-system.pages.dev/index.html?shop=default&table=1&demo=1`  
   スクショ or 短文を `docs/` か Discord 下書きに残す（有料ツール不要）。
2. **紹介経由リードをOpsで確認**  
   `referralShopId` 付きリードを優先クローズ（年払い誘導）。
3. **紹介クレジットの清算**  
   Store の共有回数メモを見て、トライアル延長を手動で反映（将来は自動化）。
4. **LP文言のA/Bはコードで**  
   広告ではなく PR でヒーロー文を微調整 → デプロイ無料（Pages）。

### やらないこと（現金が要る／効きが悪い）

- Google / Meta 広告
- インフルエンサー有償起用
- 展示会ブース課金
- 「とりあえずAWSに移行」などのコスト増

## 4. 獲得単価ゼロの戦術メニュー

| 戦術 | やり方 | 期待 |
|------|--------|------|
| Product-led | 客席透かし → LP | 利用店舗が増えるほど露出が増える |
| デモ病毒 | オーナーがデモを同業者LINEに送る | Store「投稿文をコピー」 |
| コンテンツ | X/Noteに「モバイルオーダー比較」「人手不足×QR」を自作投稿 | 広告なし。Cursorが下書き可 |
| SEO | LPの構造化データ・比較表・料金の公開 | 中長期の無料流入 |
| パートナー | 会計事務所・厨房機器屋に紹介リンクだけ渡す | 現金インセンティブなし。成功報酬は後日売上から |
| 希少性 | `introSlotsRemaining` を月次更新 | 無料だが転換を急がせる |

## 5. 売上→Cursor再投資ルール（提案）

現金を創業者から入れない前提の配分例:

| 優先 | 使い道 | 目安 |
|------|--------|------|
| 1 | Cloudflare Paid（$5） | 固定で先に払う |
| 2 | Cursor 席 + Agents hard limit | 月の新規年払いの **10%まで** |
| 3 | 残り | 生活費 / 再投資 / 税金用に残す |

例: Growth年払い1件（初回〜¥20万）→ Cursor予算上限 ¥2万/月を3ヶ月確保、など。

## 6. 計測（無料）

| 指標 | 見方 |
|------|------|
| 紹介リード数 | Ops リードの `referralShopId` / `utm_*` |
| デモ流入 | `utm_campaign=zero_cash` |
| 転換 | トライアル→`subscribed` |
| Cursor支出 | cursor.com usage（hard limit） |
